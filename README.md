## Esempio di uso di Power BI

Scenario: vuoi analizzare le vendite mensili di un negozio.

1. Apri **Power BI Desktop**.
2. Seleziona **Ottieni dati** e importa un file Excel (`vendite.xlsx`) con colonne come:
   - `Data`
   - `Prodotto`
   - `Categoria`
   - `Quantità`
   - `Prezzo`
3. Nel pannello **Report**, crea:
   - un grafico a colonne con `Categoria` sull'asse e `Somma di Quantità` nei valori;
   - una scheda con il totale vendite (`Quantità * Prezzo`).
4. Aggiungi uno **Slicer** sulla colonna `Data` per filtrare per mese.
5. Pubblica il report su **Power BI Service** per condividerlo con il team.
